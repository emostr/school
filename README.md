# edway.space

Школьная платформа, которую школа ставит на свой сервер: расписание, домашние задания, конспекты, посещаемость и проверочные работы на бумаге с автоматической проверкой сканов.

Одна установка — одна школа. Данные не уходят никуда за пределы сервера.

## Что умеет

**Расписание.** Постоянная сетка класса хранится версиями: новая сетка действует с выбранной даты, прежние остаются в архиве — по ним видно, как класс учился в любую прошедшую неделю. Поверх сетки — изменения на конкретный день: замена учителя, предмета или кабинета, отмена урока, дополнительный урок. Делёные уроки (иностранный, информатика) ставятся по подгруппам. Звонки, пяти- или шестидневка и каникулы задаются один раз на школу. Есть «лист замен» на день для учительской и предупреждение, если учитель или кабинет в одно время стоят у двух классов.

**Домашние задания.** Привязаны к расписанию: кнопка «к следующему уроку» находит ближайший урок предмета, список уроков дня подсказывает номер. Текст с формулами, фото и PDF во вложениях. Встроенные заготовки («§ и вопросы», «рабочая тетрадь», «выучить правило»…) и личные заготовки каждого автора. Архив с поиском. Задания видны и на сетке расписания — прямо под уроком.

**Конспекты.** Два способа: просто приложить фото доски или PDF либо набрать в редакторе на TipTap — заголовки, таблицы, цитаты, код, выравнивание, формулы KaTeX в строке и отдельной строкой. Больше сотни заготовок LaTeX с поиском и живым предпросмотром, заготовки целых блоков (определение, теорема с доказательством, задача с решением, лабораторная, хронология, словарь). Текст можно править и в Markdown — формулы пишутся как `$…$` и `$$…$$`.

**Посещаемость.** Отметка урока в один клик: присутствует, болен, отсутствует по уважительной или по неуважительной причине. Табель класса за любой период с итогами по ученику (пропущено уроков и дней) и выгрузкой в CSV. Ученик видит свои пропуски. Учитель отмечает только на своих уроках, классный руководитель — в своём классе по всем предметам, завуч — везде.

**Электронный журнал.** Оценки 1–5 по предметам за урок, с видом работы: работа на уроке, устный ответ, домашняя, самостоятельная, проверочная, контрольная, диктант, сочинение, лабораторная, проект, итоговая. У каждого вида свой вес (контрольная — 3, ответ на уроке — 1), средний балл считается взвешенным. Журнал — сетка «ученики × уроки предмета» из расписания, рядом с оценками видны пропуски. Оценка в клетку или колонкой всему классу за одну работу; учебные периоды (четверти, триместры) задаются в настройках школы. Классному руководителю и завучу — сводная ведомость класса по всем предметам. Ученик и родитель видят дневник: оценки по предметам, средние, свежие оценки на главной. Оценки проверенных тестов переносятся в журнал одной кнопкой.

**Родители.** Учётная запись родителя привязана к одному или нескольким детям и видит то же, что ученик: расписание, задания, конспекты, посещаемость и оценки — только на чтение, с переключателем между детьми. Родителем может быть и сотрудник школы. Завуч заводит родителя прямо из карточки класса.

**Тесты.** Модуль проверочных работ перенесён без изменений логики: конструктор с четырьмя типами заданий и формулами, до четырёх вариантов, шкала оценок, печать комплектов бланков, загрузка сканов пачкой — каждый лист сам находит своего ученика по коду, закрытые задания проверяются распознаванием, развёрнутые — учителем. Разбор заданий по классу, журнал оценок с качеством знаний и успеваемостью, доступ к тесту коллегам.

**Оформление.** Собственная дизайн-система в духе Metro (Windows 8): плоские плитки, прямые углы, Open Sans, синий акцент. Тёмная тема по умолчанию, светлая — в настройках. Уведомления на выбор — тосты в углу или окно-полоса посреди экрана, их можно проверить прямо в настройках.

## Кто что может

Ролей нет — у учётной записи набор привилегий. Завуч может одновременно вести уроки и быть классным руководителем; классный руководитель — не привилегия, а связь учителя с классом.

| | Расписание | Задания и конспекты | Посещаемость | Журнал | Тесты | Учётные записи |
|---|---|---|---|---|---|---|
| Ученик | своего класса | читает | свои пропуски | свой дневник | — | — |
| Родитель | класса ребёнка | читает | пропуски ребёнка | дневник ребёнка | — | — |
| Доверенный ученик | своего класса | публикует в своём классе | свои пропуски | свой дневник | — | — |
| Учитель | любого класса, своё | по своим предметам | на своих уроках | ставит по своим предметам | свои и общие | — |
| Классный руководитель | правит сетку своего класса | в своём классе | в своём классе | видит свой класс, сводная ведомость | | выдаёт пароли ученикам и родителям, назначает доверенных |
| Завуч | правит любое | везде | везде | везде | свои и общие | заводит всех, в том числе завучей |
| Системный администратор | — | — | — | — | — | заводит завучей, сбрасывает доступ |

Системный администратор настраивает школу (название, часовой пояс, учебная неделя, звонки, учебные периоды) и видит состояние сервера, но учебных данных не видит — его маршруты отделены на уровне API.

Свободной регистрации нет. Учётную запись заводят завуч (или администратор — для завучей): логин составляется транслитом из фамилии и инициалов (`ivanova.mp`), временный пароль показывается один раз — его можно напечатать карточками и раздать. При первом входе временный пароль меняется; завучу и администратору обязательно подключить второй фактор (TOTP), остальным — по желанию.

## Установка

Нужен сервер на Debian 12/13 (подойдёт и Ubuntu) и домен, A-запись которого указывает на сервер.

```bash
git clone https://github.com/emostr/school.git
cd school
cp deploy.conf.example deploy.conf
nano deploy.conf          # домен, почта для Let's Encrypt, при желании — порт и каталог
sudo ./deploy.sh
```

Скрипт ставит Docker, NGINX и certbot, генерирует секреты, собирает и запускает контейнеры, получает сертификат Let's Encrypt (и настраивает его продление) и создаёт системного администратора. В конце печатается адрес, логин и временный пароль:

```
  Вход системного администратора
    логин:            admin
    временный пароль: ge5LqcUKHDC7F3
```

Дальше:

1. Войдите, смените пароль и подключите приложение-аутентификатор (Яндекс Ключ, Google Authenticator, Aegis). Сохраните резервные коды.
2. В разделе «школа» задайте название, часовой пояс и звонки.
3. В разделе «завучи и доступ» заведите завуча и передайте ему логин с паролем.
4. Завуч в «справочниках» добавляет стандартный набор предметов и кабинеты, в «классах» заводит классы и вставляет списки учеников колонкой из журнала, в «людях» — учителей. Сетку расписания составляет он или классный руководитель.

Полезные ключи:

- `sudo ./deploy.sh --check` — проверить конфигурацию, DNS и порты, ничего не меняя;
- `sudo ./deploy.sh --skip-packages` — не трогать apt-пакеты;
- `sudo ./deploy.sh --config /путь/deploy.conf` — другой файл конфигурации.

Повторный запуск — это обновление: секреты сохраняются, перед сборкой снимаются дамп базы и архив загруженных файлов (`APP_DIR/backups`, хранится `BACKUP_KEEP` копий).

```bash
cd /opt/edway && git pull && sudo ./deploy.sh
```

`TLS_MODE` в `deploy.conf`: `letsencrypt` (по умолчанию), `selfsigned` — для закрытой сети, `off` — если HTTPS обеспечивает внешний прокси.

### Обслуживание

Команды выполняются из каталога платформы (`APP_DIR`, по умолчанию `/opt/edway`):

```bash
sudo docker compose logs -f backend                         # журнал API
sudo docker compose exec backend npm run admin:reset        # вернуть доступ администратору
sudo docker compose exec backend npm run admin:init         # создать администратора, если его нет
sudo docker compose exec backend npm run demo:seed          # показательные данные (не для боевой школы)
```

`admin:reset` выдаёт администратору новый временный пароль и снимает второй фактор — на случай, если потерян и телефон, и резервные коды.

## Как устроено

```
 браузер ──HTTPS──▶ NGINX хоста (сертификат, certbot)
                        │ 127.0.0.1:HTTP_PORT
                        ▼
                 ┌─ web: NGINX + собранный Angular ─┐
                 │        /api ▼                     │  docker compose
                 │  backend: NestJS на Fastify       │
                 │        ▼                          │
                 │  postgres: PostgreSQL 18          │
                 └───────────────────────────────────┘
```

- **Фронтенд:** TypeScript, Angular 22 (standalone, сигналы, zoneless), Tailwind CSS 4, TipTap 3, KaTeX.
- **Бэкенд:** TypeScript, NestJS 12 на Fastify, Prisma 7, PostgreSQL 18 (JSONB — для снимков тестов, ответов, звонков и настроек), sharp, tesseract.
- **Сервер:** NGINX, Docker, Debian.

Сканы, фото и PDF лежат в томе `uploads`, а не в базе. Файлы отдаёт API с проверкой прав: картинки контрольных видны только учителям, вложения — только тем, кто видит класс.

### Модель данных

```
School ── настройки, звонки
Account ──< AuthSession, BackupCode        привилегии: STUDENT, TRUSTED, TEACHER, HEAD, PARENT
        ──< ParentLink >── Account          родитель и ребёнок
SchoolClass ──< Student (место ученика в классе, с архивом)
            ──< ScheduleVersion ──< ScheduleLesson     постоянная сетка версиями
            ──< ScheduleChange                         изменения на дату
            ──< Homework ──< Attachment
            ──< Note ──< Attachment
            ──< Attendance
            ──< Grade                                  оценки: вид работы, вес, урок
            ──< Assignment ──< Work ──< ScanPage       модуль тестов
Subject, Room, Holiday                                 справочники
Test ──< Question, TestShare
```

Всё с архивом. Перевод класса на следующий год (7Б → 8Б) создаёт новую запись, а старая уходит в архив вместе со своим расписанием, заданиями, посещаемостью и работами; ученики переходят в новый класс. Удаление учётных записей, заданий и конспектов мягкое.

### Безопасность

- Пароли и резервные коды хешируются scrypt; второй фактор — TOTP по RFC 6238.
- Сессия — JWT в httpOnly-cookie, учитывается в базе: сеансы видны в настройках и отзываются по одному или все сразу. Смена пароля завершает остальные сеансы.
- Пока временный пароль не сменён (а у завуча и администратора — не подключён второй фактор), API не отдаёт данных.
- Права проверяются на сервере для каждого действия; маршрут без явной пометки закрыт для администратора.
- Разметка из редакторов очищается на сервере (sanitize-html) по белому списку.
- Строгий CSP без встроенных скриптов, вход ограничен по частоте запросов.

## Разработка

Нужны Node.js 24+, PostgreSQL 18 и (для распознавания бланков) tesseract с русским языком: `apt install tesseract-ocr tesseract-ocr-rus` или `brew install tesseract tesseract-lang`.

```bash
# бэкенд — http://localhost:3100/api
cd backend
cp .env.example .env            # DATABASE_URL, JWT_SECRET
npm install
npx prisma migrate dev
npm run build && npm run admin:init && npm run demo:seed
npm run dev

# фронтенд — http://localhost:4200, /api проксируется на :3100
cd frontend
npm install
npm start
```

`demo:seed` заводит два класса с учениками, учителей, родителя, сетку расписания, четверти, оценки, задания и конспект; пароль у всех — `demo-password-2026` (меняется ключом `--password=`).
